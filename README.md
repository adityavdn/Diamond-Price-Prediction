# 💎 Diamond Price Prediction

![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)
![Retail](https://img.shields.io/badge/Retail-Pricing-purple.svg)

## 📖 Overview

Regression model to predict diamond prices based on the 4Cs (Carat, Cut, Color, Clarity) and additional physical measurements. Provides accurate market value estimates.

## 🎯 Features

- Diamond price estimation
- 4Cs analysis
- Market trend insights
- Quality assessment

## 🛠️ Tech Stack

- Scikit-learn, XGBoost
- Pandas, NumPy
- Matplotlib, Seaborn

## 🚀 Usage

```bash
git clone https://github.com/adityavdn/Diamond-Price-Prediction.git
pip install -r requirements.txt
jupyter notebook
```

## 📊 Key Features

- Carat (Weight)
- Cut Quality
- Color Grade
- Clarity, Depth, Table
